# The Villages Triathlon Club

Simple static website for [thevillagestriclub.github.io](https://thevillagestriclub.github.io).

## Files

| File | Purpose |
|------|---------|
| `index.html` | Main page – training schedule, races, contacts |
| `styles.css` | Styles |
| `logo.jpg` | Club logo |

## Publish on GitHub Pages

1. Go to your repo: https://github.com/thevillagestriclub/thevillagestriclub.github.io
2. Upload (or push) these three files to the **root** of the `main` branch.
3. In the repo: **Settings → Pages**
4. Under **Build and deployment**:
   - Source: **Deploy from a branch**
   - Branch: **main** / **/** (root)
5. Save. After a minute or two the site will be live at:

   **https://thevillagestriclub.github.io**

## Editing later

- Change training times or contacts → edit `index.html`
- Tweak colors or layout → edit `styles.css`
- Replace the logo → overwrite `logo.jpg` (keep the same filename)

No build step, no Node, no Jekyll required. Just HTML + CSS.

## Content source

Training and contact details come from the Club Activity & Event Guide (Nov 2026).
